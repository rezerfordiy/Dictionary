# 西瓜
## 📝 Значение
арбуз
## 📖 Примеры
- 吃西瓜。 — Есть арбуз.
- 一个西瓜。 — Один арбуз.
- 西瓜很甜。 — Арбуз очень сладкий.

## 🔍 Особенности
- Состоит из 西 (запад) и 瓜 (тыква, бахчевая культура).
- Очень популярный летний фрукт в Китае.

## ⚠️ Ошибки новичков
- Не путать с 南瓜 (nánguā) — тыква.
- Счётное слово для арбузов — 个 (gè).
