# 商店
## 📝 Значение
магазин, лавка
## 📖 Примеры
- 去商店。 — Идти в магазин.
- 商店关门了。 — Магазин закрыт.
- 这家商店很大。 — Этот магазин большой.

## 🔍 Особенности
- Состоит из 商 (торговля) и 店 (лавка).
- Общее слово для любого магазина (кроме супермаркетов, которые часто называют 超市).

## ⚠️ Ошибки новичков
- Не путать с 商场 (shāngchǎng) — торговый центр (более крупный).
- Не говорят *商店里* в значении 'в магазине' — используется 在商店 (в магазине).
