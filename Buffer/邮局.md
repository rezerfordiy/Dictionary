# 邮局
## 📝 Значение
почта, почтовое отделение
## 📖 Примеры
- 去邮局寄信。 — Идти на почту отправить письмо.
- 邮局在哪儿？ — Где почта?
- 邮局关门了。 — Почта закрылась.

## 🔍 Особенности
- Существительное, обозначающее почтовое отделение.
- Состоит из 邮 (почта) и 局 (контора, бюро).
- Счётное слово: 一家邮局.

## ⚠️ Ошибки новичков
- Не путать с 邮箱 (yóuxiāng) — почтовый ящик.
- Не путать с 快递 (kuàidì) — курьерская служба.
