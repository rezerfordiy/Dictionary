# 桌子
## 📝 Значение
стол
## 📖 Примеры
- 桌子上边有书。 — На столе книга.
- 一张桌子。 — Один стол.
- 搬桌子。 — Передвинуть стол.

## 🔍 Особенности
- Существительное с суффиксом 子.
- Счётное слово: 张 (zhāng) — для плоских предметов.
- Основа 桌 может использоваться в сложных словах: 书桌 (письменный стол), 餐桌 (обеденный стол).

## ⚠️ Ошибки новичков
- Не путать с 椅子 (yǐzi) — стул.
- Счётное слово не 个, а 张: 一张桌子.
