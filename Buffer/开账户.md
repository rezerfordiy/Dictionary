# 开账户
## 📝 Значение
открыть счёт (в банке)
## 📖 Примеры
- 我想开账户。 — Я хочу открыть счёт.
- 在银行开账户。 — Открыть счёт в банке.
- 开账户需要证件。 — Для открытия счёта нужны документы.

## 🔍 Особенности
- Устойчивое выражение для банковского счёта.
- Состоит из 开 (открывать) и 账户 (счёт).

## ⚠️ Ошибки новичков
- Не говорят 开账号 — 账号 это номер счёта, открывают 账户.
- Не путать с 开户 (kāihù) — тоже открыть счёт, более формально.
