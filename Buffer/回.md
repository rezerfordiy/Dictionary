# 回
## 📝 Значение
возвращаться; раз (счётное слово); отвечать
## 📖 Примеры
- 回家。 — Возвращаться домой.
- 回学校。 — Вернуться в школу.
- 我回你电话。 — Я тебе перезвоню (отвечу на звонок).
- 去过一回。 — Был один раз.

## 🔍 Особенности
- Основное значение — движение обратно, возвращение.
- Также используется как счётное слово для количества раз.
- Может означать 'отвечать' в составе фраз типа 回信 (ответить на письмо), 回电话 (перезвонить).

## ⚠️ Ошибки новичков
- Не путать с 去 (qù) — идти туда. 回去 — вернуться туда, 回来 — вернуться сюда.
- В значении 'возвращаться в страну' обычно говорят 回国, не *回国家*.
