# 间
## 📝 Значение
промежуток, пространство; счётное слово для комнат
## 📖 Примеры
- 两间房。 — Две комнаты.
- 中间。 — В середине.
- 时间。 — Время. (здесь 间 в составе слова)

## 🔍 Особенности
- Как счётное слово используется для помещений: 一间教室.
- Входит в слова 时间, 房间, 中间.

## ⚠️ Ошибки новичков
- Не путать с 见 (jiàn) — видеть.
- Не путать с 简 (jiǎn) — простой.
