# 前边
## 📝 Значение
впереди, передняя сторона, перед
## 📖 Примеры
- 前边有车。 — Впереди машина.
- 学校前边。 — Перед школой.
- 往前边走。 — Идти вперёд.

## 🔍 Особенности
- Существительное и послелог для обозначения передней стороны.
- Состоит из 前 (перед) и 边 (сторона).
- Взаимозаменяемо с 前面 (qiánmiàn).
- Используется для указания местоположения и направления.

## ⚠️ Ошибки новичков
- Не путать с 后边 (hòubiān) — сзади (антоним).
- Не путать с 以前 (yǐqián) — раньше, до (о времени).
