# 附近
## 📝 Значение
поблизости, в окрестностях, рядом, близлежащий
## 📖 Примеры
- 附近有超市吗？ — Поблизости есть супермаркет?
- 我家附近。 — Рядом с моим домом.
- 附近的商店。 — Близлежащие магазины.

## 🔍 Особенности
- Существительное и прилагательное, обозначающее близлежащую территорию.
- Может использоваться как послелог: 学校附近 (рядом со школой).
- Охватывает более широкую зону, чем 旁边 (непосредственно сбоку).

## ⚠️ Ошибки новичков
- Не путать с 旁边 (pángbiān) — рядом, сбоку (более узкое, непосредственная близость).
- Не путать с 邻居 (línjū) — сосед (о людях).
