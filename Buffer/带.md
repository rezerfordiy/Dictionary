# 带
## 📝 Значение
нести, брать с собой; приводить; иметь при себе; содержать
## 📖 Примеры
- 带钱了吗？ — У тебя с собой деньги?
- 我带你去。 — Я отведу тебя.
- 带伞。 — Взять с собой зонт.
- 这面包带馅儿。 — Эта булочка с начинкой.

## 🔍 Особенности
- Многозначный глагол: перемещать что-то с собой, приводить человека, иметь при себе, содержать в составе.
- Широко используется в повседневном языке.
- Входит в состав фраз: 带路 (показывать дорогу), 带回来 (принести обратно).
- В отличие от 拿 (ná — взять в руки), 带 подразумевает перемещение с предметом.

## ⚠️ Ошибки новичков
- Не путать с 拿 (ná) — держать в руках. 我带书 — я взял с собой книгу; 我拿书 — я держу книгу в руках.
- Не путать с 戴 (dài) — надевать (очки, шапку).
