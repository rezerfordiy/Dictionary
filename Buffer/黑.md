# 黑
## 📝 Значение
чёрный, тёмный
## 📖 Примеры
- 黑色的衣服。 — Чёрная одежда.
- 天黑了。 — Стемнело (букв. небо стало чёрным).
- 黑咖啡。 — Чёрный кофе.

## 🔍 Особенности
- Обозначает чёрный цвет, противоположность 白 (bái) — белый.
- Может использоваться для описания темноты (как отсутствие света), а также в переносном смысле (нелегальный: 黑市 — чёрный рынок).

## ⚠️ Ошибки новичков
- Не путать с 暗 (àn) — тёмный (плохо освещённый); 黑 — это конкретный цвет.
- Не путать с 嘿 (hēi) — междометие 'эй' (другой иероглиф).
