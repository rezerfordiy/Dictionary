# 瓶
## 📝 Значение
бутылка; счётное слово для жидкостей в бутылках; ваза
## 📖 Примеры
- 一瓶水。 — Бутылка воды.
- 这个瓶子很漂亮。 — Эта бутылка очень красивая.
- 两瓶啤酒。 — Две бутылки пива.
- 花瓶。 — Ваза для цветов.

## 🔍 Особенности
- Существительное и счётное слово.
- Как счётное слово: 一瓶牛奶, 一瓶油.
- С суффиксом 子: 瓶子 (бутылка как предмет).
- В сложных словах: 热水瓶 (термос), 酒瓶 (винная бутылка).

## ⚠️ Ошибки новичков
- Не путать с 屏 (píng) — экран.
- Не говорят *一个瓶子* — правильно 一个瓶子 (один предмет) или 一瓶水 (одна бутылка воды). Счётное слово 个 для самого предмета, 瓶 — для содержимого.
