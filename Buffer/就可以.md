# 就可以
## 📝 Значение
тогда можно, сразу можно, уже можно
## 📖 Примеры
- 吃完饭就可以走了。 — После еды можно идти.
- 你打电话就可以知道。 — Ты можешь узнать, позвонив.
- 明天就可以完成。 — Завтра уже можно будет закончить.

## 🔍 Особенности
- Устойчивое сочетание, выражающее возможность или разрешение после выполнения условия.
- Состоит из 就 (тогда) и 可以 (можно).

## ⚠️ Ошибки новичков
- Не путать с 才能 (только тогда можно) — 就可以 более нейтрально, без ограничений.
- Порядок слов: условие + 就可以 + результат.
