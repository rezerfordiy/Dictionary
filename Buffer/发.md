# 发
## 📝 Значение
отправлять, выдавать, испускать; расти (о волосах)
## 📖 Примеры
- 发邮件。 — Отправить письмо.
- 发工资。 — Выдать зарплату.
- 发烧。 — Иметь температуру.

## 🔍 Особенности
- Многозначный глагол: отправлять, выдавать, излучать.
- Также может означать 'расти' (о волосах) с другим тоном fà.

## ⚠️ Ошибки новичков
- Не путать с 法 (fǎ) — закон, метод.
- Не путать с 发 (fà) — волосы (другой тон).
