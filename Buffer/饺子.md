# 饺子
## 📝 Значение
цзяоцзы (китайские пельмени)
## 📖 Примеры
- 我喜欢吃饺子。 — Я люблю есть пельмени.
- 包饺子。 — Лепить пельмени.
- 一盘饺子。 — Тарелка пельменей.
- 春节吃饺子。 — На Праздник Весны едят пельмени.

## 🔍 Особенности
- Традиционное китайское блюдо из теста с начинкой, популярно особенно на севере Китая.
- Счётное слово: 个 (один пельмень), 盘 (тарелка).
- Глагол: 包饺子 (лепить пельмени).
- Имеет культурное значение: символ богатства и объединения семьи, форма напоминает древние слитки серебра.
- Вариант: 水饺 (варёные), 蒸饺 (паровые), 煎饺 (жареные).

## ⚠️ Ошибки новичков
- Не путать с 包子 (bāozi) — паровые пирожки.
- Не говорят *一个饺子* — счётное слово 个 для одного пельменя, но для порции — 盘/份.
