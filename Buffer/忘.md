# 忘
## 📝 Значение
забывать
## 📖 Примеры
- 我忘了。 — Я забыл.
- 别忘了。 — Не забудь.
- 忘带钥匙。 — Забыть взять ключи.

## 🔍 Особенности
- Глагол забывания. Часто используется с 了.
- Может употребляться с дополнением: 忘带, 忘记.

## ⚠️ Ошибки новичков
- Не путать с 忙 (máng) — занят; разные иероглифы.
- Не путать с 记 (jì) — помнить; противоположность.
