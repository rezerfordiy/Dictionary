# 声
## 📝 Значение
звук, голос, тон; счётное слово для звуков. Больше про звук
## 📖 Примеры
- 大声一点。 — Громче (букв. громкий звук немного).
- 不要出声。 — Не издавай ни звука.
- 说一声。 — Скажи словечко (букв. скажи один звук).
- 四声。 — Четыре тона (в китайском языке).

## 🔍 Особенности
- Существительное и счётное слово для звуков и речевых действий.
- Используется для обозначения тонов в китайском языке: 声调 (shēngdiào).
- Как счётное слово: 说一声 (сказать словечко), 叫一声 (крикнуть разок).

## ⚠️ Ошибки новичков
- Не путать с 声音 (shēngyīn) — звук, голос (более общее понятие).
- В слове 声调 (тон) не заменяется на *音调* (интонация, мелодика).
