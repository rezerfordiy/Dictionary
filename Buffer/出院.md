# 出院
## 📝 Значение
выписаться из больницы
## 📖 Примеры
- 他明天出院。 — Он завтра выписывается из больницы.
- 出院后要好好休息。 — После выписки нужно хорошо отдыхать.
- 医生让他出院了。 — Врач выписал его.

## 🔍 Особенности
- Глагол с дополнением, обозначающий выписку из стационара.
- Состоит из 出 (выходить) и 院 (больница, учреждение).
- Не требует прямого дополнения: нельзя *出院医院*.
- Антоним: 住院 (ложиться в больницу).

## ⚠️ Ошибки новичков
- Не путать с 出医院 (выходить из здания больницы, не выписываться). 出院 — устойчивое выражение именно о выписке.
- Не использовать с 了 перед объектом: 他出了院 — редко, обычно 他出院了.
