# 声调
## 📝 Значение
тон (в лингвистике), интонация
## 📖 Примеры
- 汉语有四个声调。 — В китайском языке четыре тона.
- 这个字的声调是第几声？ — Какой тон у этого иероглифа?
- 声调不对，意思就变了。 — Если тон неправильный, значение меняется.

## 🔍 Особенности
- Относится к тональной системе китайского языка.
- Обозначает высоту голоса при произнесении слога.

## ⚠️ Ошибки новичков
- Не путать с 语调 (интонация всего предложения) — 声调 о тоне слога.
- Не путать с 音调 (музыкальный тон) — тоже разное.
