# 第
## 📝 Значение
префикс порядковых числительных: образует порядковые номера (первый, второй, третий...)
## 📖 Примеры
- 第一。 — Первый.
- 第二次。 — Второй раз.
- 第三课。 — Третий урок.
- 你是第几个？ — Который ты по счёту?
- 第一个星期。 — Первая неделя.

## 🔍 Особенности
- Ставится перед числом для образования порядкового числительного: 第一, 第二, 第十 (десятый).
- Порядок: 第 + число + счётное слово/существительное (第三个学生 — третий ученик).
- В отличие от русского, где есть суффиксы -ый/-ой, в китайском используется 第.
- Если без 第, число может быть количественным: 三个人 (три человека) vs 第三个人 (третий человек).

## ⚠️ Ошибки новичков
- Не путать с 弟 (dì) — младший брат (тот же тон, разный иероглиф).
- Не ставьте 第 без числительного: *第个* неверно.
- В датах для числа месяца обычно не используется 第 (五月一号, а не *五月第一号*).
