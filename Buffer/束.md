# 束
## 📝 Значение
букет, связка, пучок; счётное слово для букетов и пучков; связывать
## 📖 Примеры
- 一束花。 — Один букет цветов.
- 一束光。 — Луч света.
- 束头发。 — Связать волосы.
- 束腰带。 — Затянуть пояс.

## 🔍 Особенности
- Как счётное слово используется для букетов, пучков, лучей: 一束花, 一束光.
- Как существительное: связка, букет.
- Как глагол: связывать, ограничивать (束缚 — сковывать).
- В формальной речи может означать 'ограничивать, сдерживать'.

## ⚠️ Ошибки новичков
- Не путать с 朵 (duǒ) — счётное слово для отдельных цветков. 一朵花 — один цветок, 一束花 — букет цветов.
- Не путать с 把 (bǎ) — счётное слово для предметов с ручкой или схваченных рукой (一把花 — букет, схваченный рукой, взаимозаменяемо, но 束 подчёркивает перевязанность).
