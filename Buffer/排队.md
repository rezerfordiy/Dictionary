# 排队
## 📝 Значение
стоять в очереди
## 📖 Примеры
- 排队买票。 — Стоять в очереди за билетами.
- 请排队。 — Пожалуйста, в очередь.
- 排队等了很久。 — Долго стоял в очереди.

## 🔍 Особенности
- Обозначает стояние в очереди.
- Состоит из 排 (выстраивать) и 队 (очередь, отряд).

## ⚠️ Ошибки новичков
- Не путать с 排 (pái) — ряд; 排队 это действие.
- Не путать с 插队 (chāduì) — влезать без очереди.
