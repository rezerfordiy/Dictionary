# 眼睛
## 📝 Значение
глаз, глаза
## 📖 Примеры
- 她的眼睛很大。 — У неё большие глаза.
- 闭上眼睛。 — Закрыть глаза.
- 眼睛疼。 — Глаза болят.

## 🔍 Особенности
- Существительное, обозначающее орган зрения.
- Состоит из 眼 (глаз) и 睛 (глазное яблоко).
- Счётное слово: 一只眼睛 (один глаз), 两只眼睛 (два глаза).

## ⚠️ Ошибки новичков
- Не путать с 眼镜 (yǎnjìng) — очки.
- Не говорят *眼* отдельно в разговорной речи для обозначения глаза — обычно 眼睛.
