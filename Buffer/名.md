# 名
## 📝 Значение
имя, название; счётное слово для людей (официально)
## 📖 Примеры
- 有名。 — Известный.
- 一名学生。 — Один студент.
- 他的名字。 — Его имя. (здесь 名 в составе 名字)

## 🔍 Особенности
- Может быть существительным: имя, название.
- Как счётное слово используется для людей в официальной речи: 一名医生.

## ⚠️ Ошибки новичков
- Не путать с 明 (míng) — светлый, ясный.
- В быту для имени чаще используют 名字 (míngzi), а не 名.
