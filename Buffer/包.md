# 包
## 📝 Значение
сумка, пакет; заворачивать, упаковывать; пачка, упаковка; счётное слово для упаковок
## 📖 Примеры
- 书包。 — Рюкзак (книжная сумка).
- 一包糖。 — Пачка сахара.
- 请把礼物包起来。 — Пожалуйста, заверните подарок.
- 钱包。 — Кошелёк.
- 包子。 — Паровые пирожки (баоцзы).

## 🔍 Особенности
- Многофункциональное: существительное 'сумка, пакет', глагол 'заворачивать', счётное слово для упаковок (一包烟 — пачка сигарет).
- Счётное слово для сумок: 个 (一个包).
- Входит в состав многих слов: 面包 (хлеб), 包子 (баоцзы), 包围 (окружать).
- Отдельно 包 может означать 'включать в себя' (包含).

## ⚠️ Ошибки новичков
- Не путать с 抱 (bào) — обнимать (другой тон: bāo vs bào).
- Не путать с 饱 (bǎo) — сытый.
- При заказе 'пакет' в магазине уточняйте: 塑料袋 (пластиковый пакет) или 纸袋 (бумажный).
