# 结婚
## 📝 Значение
жениться, выходить замуж, вступать в брак
## 📖 Примеры
- 他们结婚了。 — Они поженились.
- 我想结婚。 — Я хочу жениться / выйти замуж.
- 跟他结婚。 — Выйти за него замуж.
- 结婚戒指。 — Обручальное кольцо.

## 🔍 Особенности
- Глагол с дополнением, обозначающий вступление в брак.
- Состоит из 结 (соединять) и 婚 (брак).
- Не принимает прямого дополнения: нельзя *结婚他*, правильно 跟他结婚.
- Длительное действие: 正在结婚 (находиться в процессе бракосочетания).

## ⚠️ Ошибки новичков
- Не путать с 婚礼 (hūnlǐ) — свадебная церемония (существительное).
- Не путать с 离婚 (líhūn) — разводиться (антоним).
