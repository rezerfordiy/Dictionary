# 后边
## 📝 Значение
сзади, позади, задняя сторона
## 📖 Примеры
- 后边有人。 — Сзади кто-то есть.
- 房子后边。 — За домом.
- 去后边。 — Идти назад.

## 🔍 Особенности
- Существительное и послелог для обозначения задней стороны.
- Состоит из 后 (зад) и 边 (сторона).
- Взаимозаменяемо с 后面 (hòumiàn).
- Антоним: 前边 (впереди).

## ⚠️ Ошибки новичков
- Не путать с 前边 (qiánbiān) — впереди.
- Не путать с 以后 (yǐhòu) — после, потом (о времени).
