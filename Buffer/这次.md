# 这次
## 📝 Значение
этот раз, на этот раз
## 📖 Примеры
- 这次我去。 — В этот раз пойду я.
- 这次考试很难。 — Этот экзамен сложный.
- 下次再说吧。 — Поговорим в следующий раз (противопоставление).

## 🔍 Особенности
- Указательное местоимение для обозначения текущего или ближайшего события.
- Противоположность — 下次 (следующий раз).

## ⚠️ Ошибки новичков
- Не путать с 这个 (этот предмет) — 次 используется для счётных слов раз.
- Не говорят *这次次* — правильно 这次.
