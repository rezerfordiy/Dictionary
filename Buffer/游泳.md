# 游泳
## 📝 Значение
плавать, заниматься плаванием; плавание
## 📖 Примеры
- 我会游泳。 — Я умею плавать.
- 去游泳池。 — Идти в бассейн.
- 游泳对身体好。 — Плавание полезно для здоровья.
- 他们正在游泳。 — Они сейчас плавают.

## 🔍 Особенности
- Глагол с дополнением (VO), разделяемый: 游过泳 (плавал), 游一会儿泳 (поплавать немного).
- Может быть существительным: 游泳比赛 (соревнования по плаванию).
- Состоит из 游 (плавать, гулять) и 泳 (плавать).
- Связанные слова: 游泳馆 (бассейн), 游泳衣 (купальник).

## ⚠️ Ошибки новичков
- Не путать с 游泳衣 (yóuyǒngyī) — купальник.
- Не говорят *游游泳泳* — редупликация не используется.
- Плавать в море/реке — 游泳, а в бассейне — тоже 游泳, но с указанием места.
