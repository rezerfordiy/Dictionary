# 辆
## 📝 Значение
счётное слово для колёсных транспортных средств
## 📖 Примеры
- 一辆汽车。 — Одна машина.
- 那辆自行车。 — Тот велосипед.
- 三辆公共汽车。 — Три автобуса.

## 🔍 Особенности
- Универсальное счётное слово для наземных транспортных средств на колёсах.
- Используется с: 汽车 (машина), 自行车 (велосипед), 公共汽车 (автобус), 卡车 (грузовик) и т.д.

## ⚠️ Ошибки новичков
- Не используется с летательными аппаратами (架 jià) или кораблями (艘 sōu).
- Не путать с 台 (tái) — для электроприборов и станков.
