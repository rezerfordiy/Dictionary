# 裤子
## 📝 Значение
брюки, штаны
## 📖 Примеры
- 这条裤子太长了。 — Эти брюки слишком длинные.
- 我买了一条新裤子。 — Я купил новые брюки.
- 穿裤子比穿裙子方便。 — В брюках удобнее, чем в юбке.

## 🔍 Особенности
- Счётное слово: 条 (tiáo) — для длинных предметов.
- Относится к одежде для нижней части тела.
- Связанные: 短裤 (шорты), 长裤 (длинные брюки).

## ⚠️ Ошибки новичков
- Не путать с 衣服 (yīfu) — общее понятие одежды.
- Не говорят *一件裤子* — только 一条裤子.
