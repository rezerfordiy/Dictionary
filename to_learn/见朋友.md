# 见朋友
## 📝 Значение
встречаться с другом/друзьями
## 📖 Примеры
- 我今天要去见朋友。 — Сегодня я иду встречаться с другом.
- 他想见朋友。 — Он хочет увидеться с друзьями.
- 见朋友的时候很开心。 — Когда встречаешься с друзьями, очень радостно.

## 🔍 Особенности
- Устойчивое глагольно-объектное сочетание (见 + 朋友).
- Может разделяться: 见一个朋友 (встретиться с одним другом).
- Используется в неформальном общении.

## ⚠️ Ошибки новичков
- Не путать с 见面 (jiànmiàn) — 见面 уже подразумевает встречу, не требует прямого объекта. *见面朋友* — неправильно.
- Правильно: 跟朋友见面 или 见朋友.
