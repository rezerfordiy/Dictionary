# 请
## 📝 Значение
просить, приглашать; пожалуйста (вежливое побуждение)
## 📖 Примеры
- 请坐。 — Пожалуйста, садитесь.
- 请问。 — Позвольте спросить.
- 请你帮我。 — Прошу тебя, помоги мне.
- 请他吃饭。 — Пригласить его поесть.

## 🔍 Особенности
- Многофункциональный глагол: вежливое побуждение (пожалуйста), просьба, приглашение.
- При побуждении ставится перед глаголом: 请进 (входите, пожалуйста).
- В значении 'угощать': 我请你吃饭 (я угощаю тебя обедом).
- В ответе на благодарность редко используется, в отличие от русского 'пожалуйста' (там 不客气).

## ⚠️ Ошибки новичков
- Не путать с 邀请 (yāoqǐng) — приглашать (более формальное, письменное).
- В значении 'пожалуйста' только с глаголом. Для 'пожалуйста' при передаче предмета говорят 给你.
