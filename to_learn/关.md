# 关
## 📝 Значение
закрывать; выключать; касаться, иметь отношение
## 📖 Примеры
- 关门。 — Закрыть дверь.
- 关灯。 — Выключить свет.
- 没关系。 — Не имеет значения.
- 关键。 — Ключевой момент.

## 🔍 Особенности
- Глагол: закрывать, выключать (关电视 — выключить телевизор).
- Существительное: застава, пропускной пункт (海关 — таможня).
- В составе: 关于 (о, относительно), 关系 (отношение, связь).
- Антоним: 开 (открывать).

## ⚠️ Ошибки новичков
- Не путать с 观 (guān) — смотреть, наблюдать.
- Не путать с 管 (guǎn) — управлять, труба.
