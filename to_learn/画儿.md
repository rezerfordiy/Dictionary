# 画儿
## 📝 Значение
рисунок, картина
## 📖 Примеры
- 墙上挂着一张画儿。 — На стене висит картина.
- 这张画儿真漂亮。 — Этот рисунок очень красивый.
- 小朋友，你画的画儿真好！ — Малыш, ты нарисовал отличную картинку!

## 🔍 Особенности
- Существительное, образованное от глагола 画 с суффиксом 儿 (эризация).
- Счётное слово: 张 (zhāng) или 幅 (fú) для картины.
- Без эризации 画 также может быть существительным (живопись, рисунок).

## ⚠️ Ошибки новичков
- Не путать с 花 (huā) — цветок. Произношение huàr vs huār различается.
- Не говорят *一个画儿* — нужно счётное слово 张/幅.
