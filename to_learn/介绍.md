# 介绍
## 📝 Значение
представлять (кого-то), знакомить; рекомендовать; описание
## 📖 Примеры
- 我来介绍一下，这是王先生。 — Позвольте представить, это господин Ван.
- 请你介绍一本好书给我。 — Порекомендуй мне, пожалуйста, хорошую книгу.
- 他简单介绍了公司的情况。 — Он вкратце описал ситуацию в компании.

## 🔍 Особенности
- Глагол, может принимать прямое дополнение (кого/что представляют).
- Конструкция: 给/向 + человек + 介绍 + объект (представить кому-то кого-то/что-то).
- Также используется как существительное в значении «рекомендация, описание».

## ⚠️ Ошибки новичков
- Не путать с 解释 (jiěshì) — объяснять, толковать.
- При знакомстве не говорят *介绍我*; правильно 自我介绍一下 (представиться) или 我来介绍一下。
