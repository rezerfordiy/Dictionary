# 新
## 📝 Значение
новый (по времени, состоянию)
## 📖 Примеры
- 这是我的新书。 — Это моя новая книга.
- 新年快乐！ — С Новым годом!
- 衣服是新的。 — Одежда новая.

## 🔍 Особенности
- Базовое прилагательное 'новый', антоним: 旧 (jiù) — старый.
- Образует множество слов: 新闻 (новости), 重新 (заново), 新手 (новичок).
- Может использоваться как наречие со значением 'только что, недавно' (新来的 — только что пришедший).

## ⚠️ Ошибки новичков
- Не путать с 鲜 (xiān) — свежий (о вкусе, рыбе). Для свежести продуктов чаще 新鲜.
- Не говорят *新新鲜鲜* — избыточно.
