# 用
## 📝 Значение
использовать, пользоваться, применять
## 📖 Примеры
- 我用手机查资料。 — Я пользуюсь телефоном, чтобы искать информацию.
- 这本书可以借我用一下吗？ — Можно одолжить у тебя эту книгу ненадолго?
- 用汉语怎么说这个？ — Как это сказать по-китайски?

## 🔍 Особенности
- Базовый глагол, прямое дополнение — инструмент, средство, язык.
- Часто используется с дополнением без предлога: 用筷子 (пользоваться палочками).
- В отрицании: 不用 (не нужно, не надо).

## ⚠️ Ошибки новичков
- Не путать с 有 (yǒu) — иметь. *我用一本书* неправильно для 'у меня есть книга'; правильно 我有一本书.
- Не говорят *用走路* — 'идти пешком' лучше 走/走路.
