# 父母
## 📝 Значение
родители (отец и мать)
## 📖 Примеры
- 我父母住在北京。 — Мои родители живут в Пекине.
- 父母的爱是最伟大的。 — Родительская любовь самая великая.
- 你父母身体好吗？ — Как здоровье твоих родителей?

## 🔍 Особенности
- Собирательное существительное, включает отца и мать.
- Более формальное и письменное, в быту чаще 爸爸妈妈.
- Счётное слово для уважительного упоминания: 一对父母 (пара родителей).

## ⚠️ Ошибки новичков
- Не путать с 父亲 (fùqīn) — только отец, или 母亲 (mǔqīn) — только мать.
- Не говорят *一个父母*; для 'одного из родителей' — 一位家长.
