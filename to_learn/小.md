# 小
## 📝 Значение
маленький, небольшой; младший
## 📖 Примеры
- 这个房间很小。 — Эта комната очень маленькая.
- 我弟弟还小。 — Мой младший брат ещё маленький.
- 一小杯水。 — Маленький стакан воды.

## 🔍 Особенности
- Базовое прилагательное размера и возраста.
- Также используется как префикс для уменьшительно-ласкательных форм: 小猫 (котёнок), 小朋友 (ребёнок).
- Антоним: 大 (dà) — большой.

## ⚠️ Ошибки новичков
- Не путать с 少 (shǎo) — мало (по количеству).
- Для обозначения малого количества говорят 少, для размера — 小.
