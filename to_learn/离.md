# 离
## 📝 Значение
от, отстоять от (предлог расстояния); покидать, расставаться
## 📖 Примеры
- 我家离学校很近。 — Мой дом очень близко от школы.
- 离婚不是容易的事。 — Развод — дело нелёгкое. (в значении 'покидать')
- 离考试还有两天。 — До экзамена ещё два дня.

## 🔍 Особенности
- Основное использование — предлог для указания расстояния: A 离 B + прилагательное (远/近).
- Может быть глаголом 'покидать, расставаться': 离家 (уйти из дома), 离婚 (развестись).
- Временное значение: 离 + событие + 还有 + время (до события ещё столько-то).

## ⚠️ Ошибки новичков
- Не путать с 从 (cóng) — из, от (исходная точка движения). 从 указывает на начало движения, 离 — на дистанцию.
- Не говорят *我家离学校近* без 很 в утверждении; обычно 离……很近/不远.
