# 厚
## 📝 Значение
толстый (о слое, предмете); тёплый, плотный (об одежде)
## 📖 Примеры
- 这本书很厚。 — Эта книга очень толстая.
- 冬天要穿厚衣服。 — Зимой нужно носить тёплую одежду.
- 雪下得很厚。 — Снег выпал толстым слоем.

## 🔍 Особенности
- Прилагательное, описывает большую толщину или плотность (одежды, предметов).
- Антоним: 薄 (báo) — тонкий.
- В значении 'тёплый' используется только с одеждой.

## ⚠️ Ошибки новичков
- Не путать с 粗 (cū) — толстый (о цилиндрических предметах), 厚 — о плоских слоях.
- О человеке 'толстый' говорят 胖 (pàng).
