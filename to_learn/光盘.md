# 光盘
## 📝 Значение
оптический диск (CD/DVD); программа-приложение (разговорное); пустая тарелка (в контексте еды)
## 📖 Примеры
- 我有一张学习汉语的光盘。 — У меня есть диск для изучения китайского языка.
- 请把光盘放进电脑。 — Пожалуйста, вставь диск в компьютер.
- 大家把菜吃完，要光盘。 — Доедайте блюда, нужно чтобы тарелки были чистыми (акция против пищевых отходов).

## 🔍 Особенности
- Основное значение — оптический носитель информации, также кампания «Чистая тарелка».
- Счётное слово: 张 (一张光盘).
- В последнее время активно используется в значении 'доедать всё без остатка'.

## ⚠️ Ошибки новичков
- Не путать с 磁盘 (cípán) — магнитный диск.
- В значении 'чистая тарелка' не путать с 光盘行动 (акция).
