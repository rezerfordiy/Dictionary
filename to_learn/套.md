# 套
## 📝 Значение
комплект, набор; счётное слово для комплектов, квартир, методов
## 📖 Примеры
- 我买了一套新衣服。 — Я купил комплект новой одежды.
- 这套房子很漂亮。 — Эта квартира очень красивая.
- 一套方法。 — Набор методов.

## 🔍 Особенности
- Счётное слово для комплектов (мебель, одежда, посуда), квартир, а также абстрактных систем (一套理论 — теория, система).
- Как существительное: 套装 (костюм), 套餐 (комплексный обед).
- Для квартир: 一套房子 (одна квартира) — стандартное счётное слово.

## ⚠️ Ошибки новичков
- Не путать с 条 (tiáo) — длинные предметы. 套 именно для комплекта, где несколько частей образуют целое.
- Не говорят *一个套房子* — обязательно 一套房子.
