# 差
## 📝 Значение
1) не хватать, недоставать (о времени: без); 2) разница; 3) плохой, некачественный
## 📖 Примеры
- 差五分钟八点。 — Без пяти восемь.
- 我们差三个人。 — Нам не хватает трёх человек.
- 质量太差。 — Качество слишком плохое.
- 差很多。 — Сильно отличается.

## 🔍 Особенности
- При указании времени означает 'без': X点差Y分 (без Y минут X).
- Глагол 'недоставать': 差很多 (не хватает многого).
- Прилагательное 'плохой': 差劲 (никудышный).
- Другое произношение: chāi (посылать, командировка) и cī (неровный).

## ⚠️ Ошибки новичков
- Не путать с 差点儿 (chàdiǎnr) — чуть не, едва не.
- В значении времени нельзя сказать *差八点五*, правильно: 差五分八点.
