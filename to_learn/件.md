# 件
## 📝 Значение
штука (счётное слово для одежды, дел, предметов, новостей)
## 📖 Примеры
- 我买了一件衣服。 — Я купила одну вещь (предмет одежды).
- 这是一件大事。 — Это большое дело.
- 一件行李。 — Одно место багажа.

## 🔍 Особенности
- Универсальное счётное слово для одежды (一件衬衫, 一件毛衣), дел (一件事), багажа, подарков.
- Не используется с людьми, животными и парными предметами.
- В комбинации с числительным: 一件, 两件 и т.д.

## ⚠️ Ошибки новичков
- Не путать с 条 (tiáo) — для длинных предметов (брюки, юбки).
- Не говорят *一件裤子* — для брюк 一条裤子.
