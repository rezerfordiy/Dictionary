# 后
## 📝 Значение
после, позади, потом; после (время/пространство)
## 📖 Примеры
- 饭后散步对身体好。 — После еды гулять полезно для здоровья.
- 房子后面有一个花园。 — Позади дома есть сад.
- 三天后见。 — Увидимся через три дня.

## 🔍 Особенности
- Выступает как существительное (задняя часть, место позади) или как послеслог (после).
- Временная конструкция: событие + 后 (после события); период времени + 后 (через период).
- Пространственная конструкция: объект + 后面/后边 (позади объекта).

## ⚠️ Ошибки новичков
- Не путать с 後 (традиционная форма) — значение одинаковое.
- Для «позади» используют 后面 или 后边, а просто 后 обычно только в составе слов типа 后门 (задняя дверь).
