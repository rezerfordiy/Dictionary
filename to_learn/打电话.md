# 打电话
## 📝 Значение
звонить по телефону
## 📖 Примеры
- 我一会给你打电话。 — Я скоро тебе позвоню.
- 他正在打电话。 — Он сейчас говорит по телефону.
- 别打电话了，上课了。 — Прекрати звонить, урок начался.

## 🔍 Особенности
- Глагольно-объектное сочетание (разделяемое): можно 打一个电话 (сделать один звонок), 打了很长时间电话 (долго говорил по телефону).
- Для указания адресата используется 给: 给某人打电话.
- В разговоре может сокращаться до 打 (我打给你).

## ⚠️ Ошибки новичков
- Не путать с 接电话 (jiē diànhuà) — отвечать на звонок.
- Не говорят *打一个电话给* без дополнения; обязательно 给 + человек.
