# 洗澡
## 📝 Значение
принимать ванну/душ, мыться
## 📖 Примеры
- 我每天晚上洗澡。 — Я принимаю душ каждый вечер.
- 洗澡间。 — Ванная комната.
- 洗个热水澡。 — Принять горячую ванну.
- 先洗澡再睡觉。 — Сначала помыться, потом спать.

## 🔍 Особенности
- Глагол с дополнением, разделяемый: 洗个澡, 洗过澡.
- Означает полноценное мытьё тела.
- Счётное слово для действия: 洗一次澡 (помыться один раз).

## ⚠️ Ошибки новичков
- Не путать с 洗手 (xǐshǒu) — мыть руки.
- Не говорят *洗澡澡*.
