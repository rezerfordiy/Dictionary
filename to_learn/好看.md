# 好看
## 📝 Значение
красивый, приятный на вид; интересный (о книгах, фильмах)
## 📖 Примеры
- 这件衣服很好看。 — Эта одежда очень красивая.
- 你觉得这个电影好看吗？ — Как тебе фильм, интересный?
- 她长得很好看。 — Она очень красивая.

## 🔍 Особенности
- Прилагательное, описывает привлекательность для глаз.
- Состоит из 好 (хорошо) + 看 (смотреть).
- Используется для людей, вещей, зрелищ.

## ⚠️ Ошибки новичков
- Не путать с 漂亮 (piàoliang) — красивая (чаще о внешности женщин). 好看 универсальнее.
- Не говорят *很好看好看* — только 很好看 или 非常好看.
