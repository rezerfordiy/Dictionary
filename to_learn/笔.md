# 笔
## 📝 Значение
ручка, кисть (письменная принадлежность); счётное слово для сумм денег
## 📖 Примеры
- 一支笔。 — Одна ручка.
- 我有一支新笔。 — У меня новая ручка.
- 用笔写。 — Писать ручкой.
- 一笔钱。 — Одна сумма денег.

## 🔍 Особенности
- Существительное: кисть, ручка, карандаш (общее название для пишущих инструментов).
- Как счётное слово: для сумм денег, сделок (一笔钱, 一笔生意).
- Счётное слово для ручек: 支 (zhī).
- Входит в слова: 铅笔 (карандаш), 钢笔 (перьевая ручка).

## ⚠️ Ошибки новичков
- Не путать 笔 (bǐ) — ручка и 比 (bǐ) — сравнивать.
- Не говорят *一个笔*, счётное слово 支: 一支笔.
