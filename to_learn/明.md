# 明
## 📝 Значение
следующий (о дне, годе); ясный, светлый; понимать
## 📖 Примеры
- 明天。 — Завтра.
- 明年。 — В следующем году.
- 明亮。 — Яркий, светлый.
- 明白。 — Понимать.

## 🔍 Особенности
- Связанная морфема, самостоятельно используется редко.
- В значении 'следующий' образует слова: 明天, 明年, 明晚 (завтра вечером).
- Значение 'ясный, светлый': 明亮, 明月 (яркая луна).
- Значение 'понимать': 明白 (ясно, понятно).

## ⚠️ Ошибки новичков
- Не путать с 名 (míng) — имя, слава (тот же тон, разные иероглифы).
- Не используется изолированно как 'завтра' — только 明天.
