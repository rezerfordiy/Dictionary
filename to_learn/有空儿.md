# 有空儿
## 📝 Значение
иметь свободное время, быть свободным
## 📖 Примеры
- 明天你有空儿吗？ — Завтра у тебя есть свободное время?
- 有空儿来我玩儿。 — Когда будет свободное время, приходи поиграть.
- 今天没空儿，改天吧。 — Сегодня нет времени, давай в другой день.

## 🔍 Особенности
- Разделяемый глагол: 有 + 空儿, можно вставить 点儿: 有点儿空儿 (есть немного времени).
- Эризованная форма 空 (kòng) + 儿.
- Отрицание: 没空儿 (нет времени).

## ⚠️ Ошибки новичков
- Не путать с 有空间 (yǒu kōngjiān) — иметь пространство.
- Не говорят *我是有空儿*; правильно 我有空儿.
