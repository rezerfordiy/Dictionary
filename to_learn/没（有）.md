# 没（有）
## 📝 Значение
не иметь; не (отрицание для глаголов завершённого действия и для 有)
## 📖 Примеры
- 我没有钱。 — У меня нет денег.
- 他没来。 — Он не пришёл.
- 没有时间。 — Нет времени.
- 还没吃饭。 — Ещё не ел.

## 🔍 Особенности
- Отрицание для глагола 有 (иметь): 没有 (не иметь).
- Отрицание для завершённого действия в прошлом (ставится перед глаголом): 没去 (не ходил).
- Не используется с 了: неправильно *没去了*, правильно 没去.
- В кратком ответе: 没有 (нет).

## ⚠️ Ошибки новичков
- Не путать с 不 (bù) — отрицание для привычных действий, будущего, прилагательных. 没有 — только прошедшее завершённое или отсутствие.
- Нельзя сказать *不有*, всегда 没有.
