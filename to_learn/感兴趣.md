# 感兴趣
## 📝 Значение
интересоваться, испытывать интерес
## 📖 Примеры
- 我对中国历史很感兴趣。 — Я очень интересуюсь историей Китая.
- 他好像不感兴趣。 — Кажется, ему неинтересно.
- 你对什么最感兴趣？ — Что тебя больше всего интересует?

## 🔍 Особенности
- Глагольно-объектное сочетание: 感 (чувствовать) + 兴趣 (интерес).
- Обязательное управление: 对 + объект + 感兴趣.
- Может быть разделено: 感过兴趣 (интересовался когда-то).

## ⚠️ Ошибки новичков
- Не говорят *我感兴趣中国历史* без 对.
- Не путать с 有意思 (yǒu yìsi) — интересный, забавный.
