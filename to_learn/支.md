# 支
## 📝 Значение
счётное слово для длинных тонких предметов (ручки, карандаши, сигареты, палочки); поддерживать
## 📖 Примеры
- 一支笔。 — Одна ручка.
- 一支烟。 — Одна сигарета.
- 三支筷子。 — Три палочки для еды.
- 支持。 — Поддерживать.

## 🔍 Особенности
- Счётное слово для длинных предметов: ручек, карандашей, палочек, сигарет, свечей.
- Как глагол: поддерживать (支持 zhīchí), устанавливать (支起).
- Отличается от 只 (zhǐ) — счётного слова для животных и одного из пары.
- Также может означать 'отделение, филиал': 支行 (филиал банка).

## ⚠️ Ошибки новичков
- Не путать с 只 (zhǐ) — только; счётное слово для животных и парных предметов (一只手 — одна рука).
- Не путать с 枝 (zhī) — ветка; счётное слово для цветов с веточкой (一枝花).
