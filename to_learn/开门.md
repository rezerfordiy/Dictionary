# 开门
## 📝 Значение
открывать дверь; начинать работу (о магазине, учреждении)
## 📖 Примеры
- 请开门。 — Откройте дверь, пожалуйста.
- 商店几点开门？ — Во сколько открывается магазин?
- 门开着，直接进来吧。 — Дверь открыта, заходи.
- 开门见山。 — Говорить прямо (идиома).

## 🔍 Особенности
- Глагол с дополнением (VO). Состоит из 开 (открывать) и 门 (дверь).
- Переносное значение: начало рабочего дня заведения.
- Разделяемое: 开了门, 开不了门 (не могу открыть дверь).
- Антоним: 关门 (закрывать дверь; закрываться).

## ⚠️ Ошибки новичков
- Не путать с 开门 (kāimén) — открытая дверь (прилагательное).
- Не говорят *开门门*.
