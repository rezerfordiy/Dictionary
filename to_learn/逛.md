# 逛
## 📝 Значение
гулять (без спешки), бродить (по магазинам, улицам)
## 📖 Примеры
- 周末我们去逛街吧。 — В выходные пойдём пройдёмся по магазинам.
- 他喜欢一个人在公园逛。 — Ему нравится бродить по парку в одиночестве.
- 我在上海逛了一天。 — Я целый день гулял по Шанхаю.

## 🔍 Особенности
- Глагол, подразумевает неторопливое передвижение с целью осмотра или отдыха.
- Часто сочетается: 逛街 (гулять по улицам/магазинам), 逛公园 (гулять в парке).
- Не используется для целенаправленного движения к цели.

## ⚠️ Ошибки новичков
- Не путать с 走 (zǒu) — идти (пешком). 逛 — именно праздно бродить.
- Не говорят *逛学校* (бродить по школе) без контекста праздного интереса.
