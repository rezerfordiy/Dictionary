# 问题
## 📝 Значение
вопрос; проблема, трудность
## 📖 Примеры
- 我有一个问题。 — У меня есть вопрос.
- 有问题吗？ — Есть вопросы?
- 没问题！ — Без проблем!
- 大问题。 — Большая проблема.

## 🔍 Особенности
- Существительное с двумя основными значениями: вопрос (запрос информации) и проблема (трудность).
- Счётное слово: 个.
- Ответ на извинения или просьбы: 没问题 (всё в порядке, без проблем).
- Сочетание: 解决问题 (решать проблему).

## ⚠️ Ошибки новичков
- Не путать с 提问 (tíwèn) — задавать вопрос (глагол).
- В значении 'вопрос' по теме не говорят *一个问*, только 一个问题.
