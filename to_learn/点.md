# 点
## 📝 Значение
час (при указании времени); точка; капля; заказывать; чуть-чуть
## 📖 Примеры
- 现在几点？ — Который час?
- 三点钟。 — Три часа.
- 一点水。 — Немного воды.
- 点菜。 — Заказать блюда.

## 🔍 Особенности
- Многофункциональное слово: час (几点?), счётное слово для капель, пунктов; глагол 'заказывать'.
- Время: X 点 Y 分 (X часов Y минут).
- Может редуплицироваться: 一点点 (чуть-чуть).
- Антоним для заказа: 点 — 退 (возвращать).

## ⚠️ Ошибки новичков
- Не путать с 点钟 (diǎnzhōng) — час (формально). В разговоре часто просто 点.
- Не говорят *三点点* — правильно 三点。
