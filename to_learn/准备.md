# 准备
## 📝 Значение
готовиться, подготавливать; собираться (что-то сделать)
## 📖 Примеры
- 准备考试。 — Готовиться к экзамену.
- 准备好了吗？ — Готов?
- 做准备。 — Делать приготовления.
- 准备出发。 — Готовиться к отправлению.

## 🔍 Особенности
- Глагол и существительное, обозначающее подготовку.
- Может принимать прямое дополнение: 准备晚饭 (готовить ужин).
- Как модальный глагол: 准备去 (собираться пойти).
- Синоним: 预备 (yùbèi) — заранее подготовить (менее употребительно в разговоре).

## ⚠️ Ошибки новичков
- Не путать с 打算 (dǎsuàn) — намереваться, планировать (ментально). 准备 подразумевает реальные действия по подготовке.
- Не говорят *准准备备* — редуплицируется только 准备准备 для смягчения: 我们准备准备。
