# 画
## 📝 Значение
рисовать, чертить
## 📖 Примеры
- 他喜欢画花儿。 — Он любит рисовать цветы.
- 你能给我画一张画儿吗？ — Ты можешь нарисовать мне картинку?
- 她在黑板上画了一个图。 — Она нарисовала схему на доске.

## 🔍 Особенности
- Глагол, обозначает процесс рисования, черчения.
- Прямое дополнение — объект рисования.
- Результат действия — 画儿 (рисунок).

## ⚠️ Ошибки новичков
- Не путать с 写 (xiě) — писать. 画 акцентирует рисование, черчение.
- Не говорят *画字* — 'рисовать иероглифы', говорят 写字.
