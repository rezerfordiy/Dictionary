# 下车
## 📝 Значение
выходить (из транспорта), сходить (с автобуса/поезда/машины)
## 📖 Примеры
- 下一站下车。 — Выходите на следующей остановке.
- 我在这儿下车。 — Я выхожу здесь.
- 别忘记下车。 — Не забудь выйти.

## 🔍 Особенности
- Глагольно-объектное сочетание (разделяемое): 下了车 (вышел из транспорта).
- Антоним: 上车 (shàng chē) — садиться в транспорт.
- Уточнение транспорта: 下公共汽车, 下地铁.

## ⚠️ Ошибки новичков
- Не путать с 出去 (chūqù) — выходить (из помещения). 下车 именно о транспорте.
- Не говорят *下车了车* — тавтология.
