# 位
## 📝 Значение
счётное слово для людей (вежливое); место, позиция
## 📖 Примеры
- 各位来宾，大家好！ — Уважаемые гости, здравствуйте!
- 请问几位？ — Сколько вас (человек)? (в ресторане)
- 我预订了一个座位。 — Я забронировал одно место. (в значении 'место')

## 🔍 Особенности
- Как счётное слово — вежливая форма для людей, заменяет 个 в уважительном контексте.
- Как существительное — 'место, позиция, должность': 座位 (место для сидения), 职位 (должность).
- В сочетаниях с 各 (各位 — господа, все присутствующие), 诸 (诸位 — уважаемые господа).

## ⚠️ Ошибки новичков
- Не используйте 位 для себя: *我是一位学生* звучит высокомерно; для себя и своей группы — 个.
- Не путать с 个 (gè) — нейтральное счётное слово.
