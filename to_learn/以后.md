# 以后
## 📝 Значение
после, потом, в будущем, через (какое-то время)
## 📖 Примеры
- 下课以后。 — После уроков.
- 以后再见。 — Увидимся потом.
- 三天以后。 — Через три дня.
- 从那以后。 — С тех пор.

## 🔍 Особенности
- Существительное и наречие времени для указания на последующий момент.
- Если после события: Событие + 以后 (прийти以后 — после того, как придёшь).
- Если период времени + 以后: указывает 'через сколько' (三天以后 — через три дня).
- Антоним: 以前 (yǐqián) — до, раньше.

## ⚠️ Ошибки новичков
- Не путать с 以后 (yǐhòu) в значении 'позже' и 然后 (ránhòu) — затем, потом (последовательность действий, а не временная точка).
- Не ставьте 以后 перед событием: нельзя *以后吃饭*, только 吃饭以后.
