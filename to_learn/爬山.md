# 爬山
## 📝 Значение
подниматься в горы, ходить в горы
## 📖 Примеры
- 周末我们去爬山吧。 — Давай в выходные пойдём в горы.
- 爬山对身体很好。 — Ходить в горы очень полезно для здоровья.
- 他喜欢爬山。 — Он любит горные прогулки.

## 🔍 Особенности
- Устойчивое глагольно-объектное сочетание (爬 + 山).
- Обозначает активный отдых, поход в горы.
- Может разделяться: 爬过几次山 (несколько раз ходил в горы).

## ⚠️ Ошибки новичков
- Не говорят *爬一座山* для выражения хобби, обычно используется 爬山.
- Для конкретной горы можно сказать 爬泰山 (подняться на гору Тай).
