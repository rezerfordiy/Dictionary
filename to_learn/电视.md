# 电视
## 📝 Значение
телевизор; телевидение
## 📖 Примеры
- 看电视。 — Смотреть телевизор.
- 电视节目。 — Телепрограмма.
- 一台电视。 — Один телевизор.
- 彩色电视。 — Цветной телевизор.

## 🔍 Особенности
- Существительное. Состоит из 电 (электричество) и 视 (зрение, смотреть).
- Счётное слово: 台 (tái) — 一台电视.
- Глагол: 看电视 (смотреть телевизор).
- Включить телевизор: 打开电视; выключить: 关上电视.

## ⚠️ Ошибки новичков
- Не путать с 电脑 (diànnǎo) — компьютер.
- Не путать с 电话 (diànhuà) — телефон.
