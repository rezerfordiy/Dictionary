# 晚饭
## 📝 Значение
ужин (вечерняя еда)
## 📖 Примеры
- 晚饭准备好了。 — Ужин готов.
- 你吃晚饭了吗？ — Ты уже поужинал?
- 晚饭后我们出去散步。 — После ужина пойдём гулять.

## 🔍 Особенности
- Существительное, обозначает вечерний приём пищи.
- С глаголом 吃: 吃晚饭 (ужинать).
- Противопоставляется 早饭 (завтрак) и 午饭 (обед).

## ⚠️ Ошибки новичков
- Не путать с 晚餐 (wǎncān) — более формальный вариант (ужин в ресторане, на мероприятии).
- Не говорят *晚晚饭* для позднего ужина — можно 夜宵 (ночной перекус).
