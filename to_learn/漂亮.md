# 漂亮
## 📝 Значение
красивый, живописный, симпатичный (о внешности, предметах)
## 📖 Примеры
- 你的衣服真漂亮。 — Твоя одежда очень красивая.
- 她长得漂亮。 — Она красивая (внешне).
- 风景很漂亮。 — Пейзаж очень живописный.

## 🔍 Особенности
- Прилагательное для описания внешней красоты людей (обычно женщин), вещей, пейзажей.
- Степень: можно усилить наречиями 很, 非常, 真.
- Может использоваться в комплиментах.

## ⚠️ Ошибки новичков
- Не путать с 美丽 (měilì) — более формальное и возвышенное 'прекрасный'.
- Для мужчин красивый чаще 帅 (shuài) — привлекательный, стильный.
