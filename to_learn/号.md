# 号
## 📝 Значение
номер; число (месяца); размер
## 📖 Примеры
- 今天几号？ — Какое сегодня число?
- 一号。 — Первое число.
- 手机号。 — Номер телефона.
- 大号。 — Большой размер.

## 🔍 Особенности
- Существительное для обозначения числа месяца, номера, размера.
- В датах: 五月一号 (1 мая).
- Для номеров: 房间号 (номер комнаты), 车牌号 (номер машины).
- В размерах: 小号 (маленький), 中号 (средний), 大号 (большой).

## ⚠️ Ошибки новичков
- Не путать с 日 (rì) — день. В устной речи для числа месяца чаще 号, в письменной — 日.
- Не путать с 叫 (jiào) — звать (произношение hào vs jiào).
