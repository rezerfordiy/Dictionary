# 分
## 📝 Значение
минута; балл, очко; делить; отделять; часть (доля)
## 📖 Примеры
- 现在三点十五分。 — Сейчас пятнадцать минут четвёртого.
- 我得了八十分。 — Я набрал 80 баллов.
- 分苹果。 — Делить яблоки.
- 三分之一。 — Одна треть.

## 🔍 Особенности
- Минута: X点Y分 (X часов Y минут).
- Баллы, очки, оценки.
- Глагол 'делить, разделять': 分开 (разделять).
- Счётное слово для долей: 三分之一 (1/3).
- Другое произношение: fèn (компонент, доля).

## ⚠️ Ошибки новичков
- Не путать с 分钟 (fēnzhōng) — минута (о промежутке времени, а не времени на часах). 分 — минута на часах, 分钟 — длительность.
- Не путать с 份 (fèn) — порция, экземпляр.
