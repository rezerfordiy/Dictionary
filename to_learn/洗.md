# 洗
## 📝 Значение
мыть, стирать; промывать
## 📖 Примеры
- 洗手。 — Мыть руки.
- 洗衣服。 — Стирать одежду.
- 洗脸。 — Умываться.
- 洗照片。 — Проявлять фотографии.

## 🔍 Особенности
- Глагол общего назначения для мытья и стирки.
- Образует множество сочетаний: 洗澡 (купаться), 洗碗 (мыть посуду).
- Может означать 'проявлять': 洗照片.
- Результативные конструкции: 洗干净 (вымыть дочиста).

## ⚠️ Ошибки новичков
- Не путать с 涮 (shuàn) — полоскать, ополаскивать.
- Не путать с 洗手间 (туалетная комната) — не глагол.
