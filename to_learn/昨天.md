# 昨天
## 📝 Значение
вчера
## 📖 Примеры
- 昨天很冷。 — Вчера было холодно.
- 我昨天没来。 — Я вчера не пришёл.
- 昨天是星期天。 — Вчера было воскресенье.
- 昨天的报纸。 — Вчерашняя газета.

## 🔍 Особенности
- Существительное, обозначающее предыдущий день.
- Антоним: 明天 (завтра).
- Обстоятельство времени без предлога.
- В составе: 昨天早上 (вчера утром), 昨天晚上 (вчера вечером).

## ⚠️ Ошибки новичков
- Не путать с 明天 (míngtiān) и 今天 (jīntiān).
- Не говорят *昨* отдельно для 'вчера' — только 昨天.
