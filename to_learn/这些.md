# 这些
## 📝 Значение
эти (указательное местоимение для множественного числа)
## 📖 Примеры
- 这些书都是我的。 — Все эти книги мои.
- 你喜欢这些花吗？ — Тебе нравятся эти цветы?
- 这些问题太难了。 — Эти вопросы слишком трудные.

## 🔍 Особенности
- Указательное местоимение множественного числа: 这 (этот) + 些 (неопределённое количество).
- Используется как определение к существительному, не требует счётного слова.
- Может выступать самостоятельно: 这些是我的 (эти — мои).

## ⚠️ Ошибки новичков
- Не путать с 这儿 (zhèr) — здесь.
- Не говорят *这些们* — 些 уже указывает на множественность.
