# 刻
## 📝 Значение
четверть (часа); момент; выреза́ть, гравировать
## 📖 Примеры
- 三点一刻。 — Четверть четвёртого (3:15).
- 立刻。 — Немедленно, тотчас.
- 时刻。 — Время, момент.
- 刻字。 — Гравировать иероглифы.

## 🔍 Особенности
- При обозначении времени: X点一刻 — X:15, X点三刻 — X:45.
- Как существительное: 时刻 (момент), 立刻 (сразу же).
- Как глагол: 刻 (вырезать).
- Счётное слово для четвертей часа: 刻 (не используется с числительными больше трёх).

## ⚠️ Ошибки новичков
- Не путать с 课 (kè) — урок.
- Не говорят *四点四刻* — максимум 三刻, для 'четыре четверти' говорят 四点整 или 四点钟.
