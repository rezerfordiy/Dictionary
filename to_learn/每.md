# 每
## 📝 Значение
каждый, всякий
## 📖 Примеры
- 每天。 — Каждый день.
- 每个人。 — Каждый человек.
- 每年。 — Каждый год.
- 他每天都跑步。 — Он каждый день бегает.

## 🔍 Особенности
- Местоимение/наречие, используется перед существительным или счётным словом для обозначения регулярности.
- Структура: 每 + счётное слово + существительное (每个人, 每本书).
- С существительными, которые сами являются счётными словами (天, 年, 月, 日), используется без дополнительного счётного слова: 每天, 每年.
- В обобщающем значении 'каждый раз' — 每次.

## ⚠️ Ошибки новичков
- Не путать с 美 (měi) — красивый.
- Не говорят *每人们* — 每个人 уже означает 'каждый человек', множественное число не требуется.
