# 水果
## 📝 Значение
фрукты
## 📖 Примеры
- 多吃水果对身体好。 — Есть больше фруктов полезно для здоровья.
- 这里有什么水果？ — Какие здесь есть фрукты?
- 苹果是我最喜欢的水果。 — Яблоко — мой любимый фрукт.

## 🔍 Особенности
- Собирательное существительное, может обозначать фрукты вообще.
- Для указания на конкретный фрукт используется название: 苹果, 香蕉 и т.д.
- Счётное слово для отдельного фрукта: 个, а для категории — 种.

## ⚠️ Ошибки новичков
- Не говорят *一个水果* для обозначения одного фрукта без указания вида; обычно говорят 一种水果 или конкретно 一个苹果.
- Не путать с 水 (shuǐ) — вода.
