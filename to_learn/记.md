# 记
## 📝 Значение
помнить, запоминать; записывать; отметка
## 📖 Примеры
- 请记下我的电话号码。 — Пожалуйста, запиши мой номер телефона.
- 你记住了吗？ — Ты запомнил?
- 我不记得这件事。 — Я не помню этого дела.

## 🔍 Особенности
- Глагол с основными значениями 'запоминать' и 'записывать'.
- Результативная форма: 记住 (запомнить), 记下 (записать).
- В значении 'помнить' обычно используется 记得 (jìde).

## ⚠️ Ошибки новичков
- Не путать с 纪 (jì) — эпоха, запись (историческая).
- Для 'помнить' чаще говорят 记得, а не просто 记.
