# Счётные слова (классификаторы) в китайском языке

Счётное слово ( classifier ) обязательно ставится между числительным / указательным местоимением / вопросительным словом **几** и существительным. Оно не переводится на русский, но грамматически необходимо.

## Когда ставить счётное слово?
- Перед любым существительным, если перед ним стоит:
  - Число (一, 二, 三…)
  - Указательное местоимение (这, 那, 哪)
  - Вопросительное слово **几** (сколько, ожидается малое число)
- Примеры:
  - 三**本**书 – три книги (счётное слово для книг — 本)
  - 这**个**人 – этот человек (универсальное счётное слово 个)
  - 几**个**苹果? – сколько яблок?

## Когда счётное слово **не** ставится?
- Если существительное само является единицей измерения (деньги, вес, длина, время):
  - 五元, 十公斤, 三米, 两天 – здесь числительное примыкает напрямую.
- В разговорной речи после **多少** (duōshao) счётное слово часто опускается (см. отдельный файл о 几 и 多少).
- В некоторых устойчивых выражениях (например, 一年, 一天 – но это счётные слова времени, они всё же есть).

## Наиболее частотные счётные слова
| Счётное слово | Употребление | Пример |
|---------------|--------------|--------|
| 个 (gè) | универсальное, для людей, предметов без своего классификатора | 一个人, 三个问题 |
| 本 (běn) | для книг, тетрадей, журналов | 两本书 |
| 张 (zhāng) | для плоских предметов (бумага, стол, фотография) | 一张纸, 三张桌子 |
| 条 (tiáo) | для длинных и гибких (рыба, река, брюки) | 一条鱼, 两条裤子 |
| 只 (zhī) | для животных, один из пары (перчатки, глаза) | 一只猫, 三只手 (руки) |
| 辆 (liàng) | для транспорта (машины, велосипеды) | 一辆车 |
| 件 (jiàn) | для одежды (пальто, рубашка), дел | 一件衣服, 一件事 |
| 杯 (bēi) | для чашек/стаканов с жидкостью | 一杯水 |
| 瓶 (píng) | для бутылок | 一瓶啤酒 |

> **Важно:** В китайском почти у каждого существительного есть «своё» счётное слово. Ошибки в выборе классификатора заметны, но не критичны – вас поймут и с 个. Однако для естественной речи стоит учить их вместе со словами.

## Упражнение
Заполните пропуски подходящими счётными словами:

1. 一___桌子  
2. 两___书  
3. 三___猫  
4. 四___汽车  
5. 这___人  

*(Ответы: 张, 本, 只, 辆, 个)*
