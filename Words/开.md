# 开
## 📝 Значение
открывать; включать; начинать; управлять (транспортом)
## 📖 Примеры
- 开门。 — Открыть дверь.
- 开灯。 — Включить свет.
- 开车。 — Вести машину.
- 开始。 — Начинать.

## 🔍 Особенности
- Очень многозначный глагол широкого употребления.
- Основные значения: открывать, включать приборы, начинать, водить транспорт.
- Входит в состав многих слов: 开始 (начинать), 开会 (проводить собрание), 开心 (радоваться).

## ⚠️ Ошибки новичков
- Не путать с 关 (guān) — закрывать, выключать (антоним).
- Для включения электроприборов используют 开, для запуска механизмов иногда 打开 (dǎkāi).
