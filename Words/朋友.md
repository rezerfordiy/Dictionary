# 朋友
## 📝 Значение
друг, приятель
## 📖 Примеры
- 我的朋友。 — Мой друг.
- 好朋友。 — Хороший друг.
- 交朋友。 — Заводить друзей.

## 🔍 Особенности
- Обозначает друга, обычно в неформальном контексте.
- Второй слог нейтрального тона.

## ⚠️ Ошибки новичков
- Не путать с 同屋 (tóngwū) — сосед по комнате.
- В китайском не говорят *女男朋友* — есть отдельные слова для подруги: 女朋友 (девушка, подруга) и 男朋友 (парень, друг-мужчина).
