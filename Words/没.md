# 没
## 📝 Значение
отрицание (не иметь, нет; также для прошлого времени)
## 📖 Примеры
- 我没有钱。 — У меня нет денег.
- 他没来。 — Он не пришёл (прошлое).
- 没事。 — Ничего страшного (букв. 'нет дела').

## 🔍 Особенности
- Основное отрицание для наличия (有) и для прошедшего времени (вместо 不).
- В сочетании с 有 даёт 没有 (нет, не иметь).

## ⚠️ Ошибки новичков
- Не путать с 不 (bù) — общее отрицание для настоящего и будущего, 没 — для прошлого и наличия.
- Не говорят *没是* — правильно 不是 (это не так).
