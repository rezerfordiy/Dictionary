# 岁
## 📝 Значение
год (возраст), счётное слово для лет
## 📖 Примеры
- 我二十岁。 — Мне двадцать лет.
- 几岁？ — Сколько лет?
- 五岁孩子。 — Пятилетний ребёнок.

## 🔍 Особенности
- Счётное слово для возраста, обозначает 'год жизни'.
- Используется только для возраста людей, не для календарных лет (для них 年).

## ⚠️ Ошибки новичков
- Не путать с 年 (nián) — календарный год.
- В вопросе о возрасте часто используют 多大, а не *多少岁* (хотя и так можно).
