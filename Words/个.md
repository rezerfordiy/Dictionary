# 个
## 📝 Значение
счётное слово (универсальное)
## 📖 Примеры
- 一个人。 — Один человек.
- 三个苹果。 — Три яблока.
- 这个。 — Этот.

## 🔍 Особенности
- Самое универсальное счётное слово, используется с большинством существительных, если нет специального счётного слова.
- Также входит в указательные местоимения: 这个 (этот), 那个 (тот).

## ⚠️ Ошибки новичков
- Нельзя использовать 个 со всеми существительными, для некоторых есть свои счётные слова (например, 本书 — книга, 条鱼 — рыба).
- Не путать с 各 (gè) — каждый (другой тон).
