# 汽车
## 📝 Значение
автомобиль, машина.
## 📖 Примеры
- 我有一辆汽车。 — У меня есть машина.
- 这辆汽车很贵。 — Эта машина дорогая.
- 汽车站 — автобусная остановка (но чаще 公共汽车站).
## 🔍 Особенности
- Состоит из 汽 (пар) + 车 (транспортное средство). Буквально «паровой экипаж», но сейчас означает автомобиль.
- Счётное слово — 辆 (liàng): 一辆汽车.
- Для автобуса обычно говорят 公共汽车 (gōnggòng qìchē) или сокращённо 公交车.
