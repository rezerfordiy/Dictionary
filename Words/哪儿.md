# 哪儿
## 📝 Значение
где, куда (вопросительное местоимение)
## 📖 Примеры
- 你去哪儿？ — Куда ты идёшь?
- 厕所在哪儿？ — Где туалет?
- 哪儿有超市？ — Где есть супермаркет?

## 🔍 Особенности
- Вопросительное местоимение для вопроса о месте или направлении.
- Разговорный вариант 哪里 (nǎlǐ), характерен для пекинского диалекта и севера.
- Может использоваться в риторических вопросах: 哪儿啊！ — Да нет же!

## ⚠️ Ошибки новичков
- Не путать с 那儿 (nàr) — там, туда (указательное местоимение).
- В формальной речи лучше использовать 哪里.
