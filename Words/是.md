# 是
## 📝 Значение
быть, являться (связка между подлежащим и именным сказуемым).
## 📖 Примеры
- 我是学生。 — Я студент.
- 这是书。 — Это книга.
- 他是老师吗？ — Он учитель?
## 🔍 Особенности
- Употребляется только для связи существительных/местоимений с другими существительными или именными группами. Не используется перед прилагательными (вместо этого просто прилагательное + 很, см. слово 很).
- Отрицание: **不是** (bù shì) — не являться.
## ⚠️ Ошибки новичков
- Главная ошибка: используют 是 перед прилагательными, например *我是好* вместо **我很好** (мне хорошо). В китайском с прилагательными связка не нужна.
- Путают с **有** (yǒu — иметь) — в русском мы говорим «у меня есть», а в китайском используют 有, а не 是.
