# 种
## 📝 Значение
вид, сорт; счётное слово для видов
## 📖 Примеры
- 一种水果。 — Один вид фруктов.
- 两种方法。 — Два способа.
- 这种书。 — Такой вид книг (эта книга такого типа).

## 🔍 Особенности
- Счётное слово для категорий, видов, типов.
- Также может быть существительным со значением 'вид, сорт'.

## ⚠️ Ошибки новичков
- Не путать с 种 (zhòng) — сажать (другой тон).
- В указательных конструкциях: 这种 (этот вид), 那种 (тот вид).
