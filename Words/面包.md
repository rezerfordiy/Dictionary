# 面包
## 📝 Значение
хлеб
## 📖 Примеры
- 我喜欢吃面包。 — Я люблю есть хлеб.
- 请给我一块面包。 — Дайте мне кусок хлеба.
- 面包店 — булочная.
## 🔍 Особенности
- Состоит из 面 (мука) + 包 (сумка, булка). Счётное слово — 块 (kuài) для куска, 个 (ge) для целой буханки.
- В китайской кухне хлеб не является основным продуктом, но слово широко используется
## ⚠️ Ошибки новичков
- Не путать с 面 (лицо, мука) и 包 (сумка) — в сочетании даёт хлеб.
