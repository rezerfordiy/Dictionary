# 课
## 📝 Значение
урок, занятие (школьное или университетское).
## 📖 Примеры
- 今天有课吗？ — Сегодня есть уроки?
- 这节课很长。 — Этот урок длинный.
- 我下午有课。 — У меня занятия после обеда.
## 🔍 Особенности
- Используется для обозначения учебного занятия.
- Счётное слово — 节 (jié) для уроков: 一节课 (один урок).
- В сочетании с глаголом 上 (shàng) образует [[上课]] (идти на урок, проводить занятие).
## ⚠️ Ошибки новичков
- Не говорят *一个课* — правильно 一节课.
