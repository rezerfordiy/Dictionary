# 几
## 📝 Значение
сколько (для небольших чисел, обычно до 10); несколько
## 📖 Примеры
- 几个人？ — Сколько человек?
- 几本书？ — Сколько книг?
- 几点？ — Который час? (букв. сколько часов?)

## 🔍 Особенности
- Вопросительное числительное, используется для вопросов о количестве, когда предполагается небольшое число.
- Отвечать можно числом или словом 几 (несколько).

## ⚠️ Ошибки новичков
- Не путать с 几 (jī) — 'столик' (редкое, но другое чтение).
- Не используют для больших чисел (например, 100) — для этого 多少 (duōshao).
